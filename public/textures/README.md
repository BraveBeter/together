# Earth texture

`earth-day.jpg` is the unmodified Blue Marble Next Generation June 2004 base map from NASA Earth Observatory.
Source: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-base/june/world.200406.3x5400x2700.jpg
Credits: Reto Stöckli, NASA Earth Observatory. Satellite imagery, not a political boundary map.
Reference: https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/
Usage: https://www.nasa.gov/nasa-brand-center/images-and-media/
Attribution is displayed beside the globe. Colour/lighting is applied at runtime; the image is unmodified.
